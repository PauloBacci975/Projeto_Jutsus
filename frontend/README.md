# Frontend - Cadastro de Jutsus

## Executar
A forma mais simples é abrir com uma extensão de servidor local, por exemplo:
- VS Code + Live Server
- ou outro servidor HTTP local

A página deve ficar em algo como:
`http://localhost:5500`

O JavaScript está configurado para chamar:
`http://localhost:8080/api/jutsus`

## Funcionalidades
- Cadastro.
- Edição.
- Consulta.
- Pesquisa por nome.
- Filtro por natureza.
- Filtro por rank.
- Visualização detalhada.
- Mensagens de sucesso/erro.
- Estado de carregamento.
- Estado sem resultados.
- Validação no frontend.
